# Luka Poropat — personal website

Static site for GitHub Pages (no build step), styled after
[ia-chow.github.io](https://ia-chow.github.io/).

| Page | What's on it |
|---|---|
| `index.html` | Bio and links |
| `research.html` | Planetary defence (NEO follow-up), solar physics & daytime seeing, robotic observatory software |
| `observations.html` | World rank, **3D map of every object observed**, statistics, object table |
| `publications.html` | MPECs crediting me (searchable), link to NASA ADS |
| `gallery.html` | AstroBin images with a lightbox |
| `faq.html` | Copyright & usage FAQ (all rights reserved) |
| `cv/Luka_Poropat_CV.pdf` | The CV (add the file here) |

## Things to add by hand

- **Optional figure:** `assets/images/research/solar.jpg` (a solar image) appears in the solar section once
  added; until then it stays hidden.
- **Headshot / CV:** replace `assets/images/headshot.jpg` (portrait, about 4:5) and `cv/Luka_Poropat_CV.pdf`
  to update them.

## Themes

The NASA-coloured theme (NASA blue #0B3D91 and red #FC3D21) is the native one for every visitor; the
button in the top-right corner switches to dark (remembered per browser). All colours are tokens in
`assets/css/main.css`. The earlier navy look and a "logbook" alternative can be previewed by adding
`?theme=light` or `?theme=logbook` to any URL. Only NASA's colours are used, never the NASA insignia.

## Data

Everything in `data/` is generated by the scripts in `tools/` (Python 3, standard library;
the gallery script also needs Pillow):

```bash
python tools/build_observations.py          # MPECs crediting me + JPL orbits -> data/observations.json
python tools/observer_rank.py               # world rank from MPEC Watch      -> data/rank.json
python tools/fetch_astrobin.py              # AstroBin images                 -> data/gallery.json
```

- `build_observations.py` reads the list of Višnjan (L01) circulars from
  [MPEC Watch](https://sbnmpc.astro.umd.edu/mpecwatch/byStation/station_L01.html), downloads each MPEC
  from the Minor Planet Center once (cached in `tools/.cache/`), keeps those whose observer details
  name me, extracts the objects from the L01 observation lines and fetches their orbits from the
  [JPL Small-Body Database API](https://ssd-api.jpl.nasa.gov/doc/sbdb.html).
  `data/mpec_index.json` remembers every circular already checked, so later runs are quick.
  Orbits are cached as well and re-fetched from JPL once they are a month old.
- `observer_rank.py` sums MPEC Watch's per-observatory "Individual Observer" tables over all
  observatories with at least 150 MPECs and ranks every individual. If MPEC Watch can't be read
  completely, it leaves the previous `data/rank.json` untouched.

The workflow in `.github/workflows/update-data.yml` runs all three every Monday (05:17 UTC), commits
the new data and publishes the site, so the statistics, the 3D map and the rank stay current on their
own. It also publishes the site after every push to `main`, and you can start it by hand from the
*Actions* tab (*Update data and publish → Run workflow*).

## Preview locally

```bash
python tools/serve.py
```

then open <http://localhost:8765>. (Opening the HTML files directly won't load the data.) The server tells
the browser to re-check every file on each load, so a normal reload always shows your latest edits.

## Publish

1. Create an empty GitHub repository named `<your-username>.github.io`.
2. In its *Settings → Pages → Build and deployment*, set *Source* to **GitHub Actions**.
3. In *Settings → Actions → General → Workflow permissions*, choose *Read and write permissions*
   so the weekly update can commit the new data.
4. Push this folder to the `main` branch. The push publishes the site at
   `https://<your-username>.github.io`; from then on it refreshes itself every Monday.
   (If you pushed before step 2, re-run the workflow from the *Actions* tab.)
